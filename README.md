# 🥁 Drum Kit

A simple, interactive browser-based drum kit that lets you play drum sounds using your keyboard or by clicking the on-screen buttons.

# Access Website on 
https://minidrumkitgame.netlify.app/

## 📁 Project Structure
```
drum-kit/
├── index.html
├── style.css
└── script.js
```

## 🎮 How to Play

Once launched, you can trigger drum sounds in two ways:

- **Click** the on-screen buttons labeled `W`, `A`, `S`, `D`, `J`, `K`, `L`
- **Press** the corresponding keys on your keyboard

| Key | Sound |
|-----|-------|
| W   | 🥁 Tom 1 |
| A   | 🥁 Tom 2 |
| S   | 🥁 Tom 3 |
| D   | 🥁 Tom 4 |
| J   | 🔔 Crash |
| K   | 👟 Kick Bass |
| L   | 🥁 Snare |

> Feel free to update the table above with your actual sound mappings.

## 🛠️ Tech Stack

- **HTML** — Structure and drum buttons
- **CSS** — Styling and button animations
- **JavaScript** — Keyboard/click event listeners and audio playback

## 🏃 Running Locally

No build tools or dependencies needed. Just clone or download the repo and open `index.html` in your browser:
```bash
# Clone the repo
git clone https://github.com/your-username/drum-kit.git

# Navigate into the folder
cd drum-kit

# Open in browser (or just double-click index.html)
open index.html
```
